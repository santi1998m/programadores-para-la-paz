Al enviar una petición POST a la ruta /registro con el siguiente JSON:

{
  "nombre": "Santiago,
  "mensaje": "Hola comunidad"
}

El servidor responde:

{
  "estado": "Datos recibidos",
  "nombre": "Santiago",
  "mensaje": "Hola comunidad"
}

La respuesta indica que el servidor recibió correctamente los datos enviados por el usuario mediante req.body.
