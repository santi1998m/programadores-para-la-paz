Durante este curso aprendí que la tecnología puede fortalecer la participación ciudadana cuando se utiliza de manera responsable. También comprendí la importancia de desarrollar plataformas seguras que protejan la información de las personas. Aprendí conceptos sobre backend, bases de datos, automatización y generación de documentos. Además, entendí que la organización comunitaria puede mejorar mediante herramientas digitales sencillas. La seguridad y la transparencia son fundamentales para generar confianza. También conocí el uso de Git y GitHub para publicar proyectos. Este curso me permitió integrar conocimientos técnicos con la participación democrática. Considero que estas herramientas pueden generar un impacto positivo en las comunidades y facilitar la acción colectiva.
